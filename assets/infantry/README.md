# Automatic Rifle Squad icon art

The TGA files in this folder are original, reproducibly drawn by `scripts/generate_infantry_icon.py` using Pillow. They contain no copied game pixels. Their five dimensions and TGA format were measured from corresponding installed Matchlock Ashigaru UI assets. The base game's icon lookup for a newly named unit has **not** been verified in-game. Inclusion in a pack means the files are available to the game, not that the game displays them.
