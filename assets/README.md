# Asset inventory

No original or licensed Chi-Ha tank model, A6M Zero model, or custom sound is in this repository. The infantry UI cards under `assets/infantry/` are original project artwork. No Creative Assembly model, texture, animation, or sound file is redistributed here.

The infantry prototype references asset and animation identifiers observed in the user's installed Fall of the Samurai tables. Their runtime resolution has not been tested. Any future contributed model must include origin, author, license, source URL, and permission for distribution before inclusion.
