# Limits and blockers

## Automatic Rifle Squad — PROVISIONAL

The local pack is structurally valid and sets `men=40`. It reuses the installed FoTS Tosa repeating-rifle row; true automatic fire is unverified. No custom model, recruitment icon, custom description text resource, or custom-battle evidence exists. Without a working GPU, campaign recruitment, battlefield behavior, animation, and stability cannot be tested. The current installed copy is an experiment, not a gameplay-certified release.

## Type 97 Chi-Ha — BLOCKED

Installed horse-drawn artillery provides an observed cannon/articulated-entity basis. It does not establish self-propelled tracks, turret rotation, armor behavior, or tank pathfinding. There is no licensed Chi-Ha model and no in-game evidence. A future artillery mechanics pack must be labeled as an artillery test; it must not be shipped as the tank unit.

## A6M Zero — BLOCKED

No visible 3D aircraft model or aircraft-named path was found in the model-pack scan. No verified game movement/flight animation or player control interface has been identified. The RPFM glTF importer needed for an easy model pipeline is documented as unimplemented. This does **not** prove that all physical aircraft implementations are unsupported. An off-map strike, projectile, or ground unit would not satisfy the requested aircraft.

## Project-wide

The executable version metadata is not a runtime build number. FoTS files are present, but exact DLC entitlement cannot be confirmed without launch. Direct key collisions were checked against decoded vanilla tables and one installed mod; other possible mod interactions remain untested. No gameplay status is marked VERIFIED.
